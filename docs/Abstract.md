# ABSTRACT

The **Pharmacy Stock Management and Medicine Sales Analysis System** is a software application developed to simplify and improve the daily operations of a pharmacy.

The system is developed using **Java** for application programming, **PostgreSQL** for database management, and **Python** for sales data analysis and visualization.

The application provides several important modules, including Medicine Management, Supplier Management, Purchase Management, Inventory Management, Expiry Management, and Sales Management. It allows users to add, view, update, and delete medicine records, manage supplier information, record medicine purchases, monitor stock levels, identify expired medicines, and maintain sales transactions.

PostgreSQL is used to store and manage pharmacy information securely. Java Database Connectivity (JDBC) enables communication between the Java application and the PostgreSQL database.

Python libraries such as Pandas, NumPy, and Matplotlib are used to analyze actual sales records from the database. The system calculates total quantity sold, total revenue, average sales, and identifies the highest-selling medicine. It also generates graphical reports to support better decision-making.

The main objective of this project is to reduce manual work, improve inventory accuracy, manage medicine expiry dates, and provide useful sales information.

This project demonstrates the practical application of Java Programming, Database Management Systems, Python Data Analysis, and Software Engineering concepts.

**Keywords:** Pharmacy Management, Java, PostgreSQL, Python, JDBC, Inventory Management, Sales Analysis, Data Visualization.
