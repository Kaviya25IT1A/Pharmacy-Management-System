# Pharmacy Stock Management and Medicine Sales Analysis System

## Objective
To manage medicine details, suppliers, purchases, stock, sales, and expiry information.
The system will also generate stock and daily-sales reports.

## Main Modules
1. Medicine Management
2. Supplier Management
3. Purchase Management
4. Inventory Management
5. Medicine Sales
6. Expiry Management
7. Reports and Python Data Analysis

## Course Integration
- Java Programming: classes, objects, methods, exception handling, collections, and JDBC.
- DBMS: tables, primary/foreign keys, SQL queries, joins, constraints, transactions, and normalization.
- Foundations of Data Science: Python, Pandas, NumPy, data preprocessing, and visualizations.
- Software Engineering: SRS, diagrams, architecture, test cases, and documentation.

## Current Status
Starter project files only. Modules will be developed step by step.
